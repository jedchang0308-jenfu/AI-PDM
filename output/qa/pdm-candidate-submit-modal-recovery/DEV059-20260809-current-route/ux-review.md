# UX review

- The modal has one clear primary action (`確認整包送審`) and one safe return action (`返回檢查`).
- X, return and Escape all have predictable local-close behavior.
- Candidate effectiveness remains a separate warning from readiness; the drawer still explains that the bundle is ready to submit while the candidate is not yet formally usable.
- The modal fits 1440×900, 1024×768 and 390×844 without horizontal overflow.
