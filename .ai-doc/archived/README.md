# .ai-doc Archive Policy

This archive keeps historical PM evidence without removing unfinished work from the active control board.

Rules:

- Unfinished work stays in `.ai-doc/dev_task.md`: Backlog, Intake, Ready, In Progress, Deferred, Blocked, Parked, and External blocker.
- Completed work is summarized in `.ai-doc/dev_task.md` and indexed in archive files.
- Protected evidence is logically archived but stays at its original path when QC scripts, package commands, or active docs reference hardcoded paths.
- Historical snapshots may be copied here before shortening active entry files.
- Do not physically move protected evidence unless the referencing scripts/docs are updated and QC is rerun in the same scope.
