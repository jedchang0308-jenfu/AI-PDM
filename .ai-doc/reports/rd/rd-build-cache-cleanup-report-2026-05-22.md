# RD Report: Build Cache Cleanup

Date: 2026-05-22
Scope: QC build failure caused by stale `.next` route type artifacts

## Changes

- Added `scripts/clean-next.mjs`.
- Added `clean:next` npm script.
- Added `prebuild` npm script so `npm run build` removes `.next` before running Next.js build.

## Reason

QC found an intermittent build failure in `.next/dev/types/routes.d.ts` after route changes. The file is generated by Next.js and can be stale after route refactors. Cleaning `.next` before production build makes the verification path deterministic.

## Notes

- This does not change runtime behavior.
- `node:sqlite` experimental warning remains a separate P2 database-driver replacement item.
- SolidWorks Add-in compile still requires a workstation with `msbuild` or `dotnet` plus SolidWorks interop dependencies.
