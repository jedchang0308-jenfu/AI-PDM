# SPEC-PDM-CHANGE-CONTROL-001：圖號進版、料號替代與 BOM 影響管制

狀態：Draft  
日期：2026-06-24  
適用系統：AI_PDM  
節點類型：交付點候選  
來源：HCS 引導模式決策整理，接續 `DEV-PDM-REVISION-001` 版次政策  

## 1. 目的

建立一套低摩擦但可追溯的 PDM 變更流程，解決圖面進版、料號替代與 BOM 是否進版之間的底層邏輯衝突。

本規格的核心目標：

- 圖號以版次為主進行管制。
- 料號無版次；若料件違反 FFF 原則，應取新料號。
- BOM 本身有版次，但不強制記錄使用的圖號版次；預設引用最新版 released 圖面。
- 圖面只做標註或文字修正、未違反 FFF 時，BOM 可不進版。
- 讓 RD 可低摩擦建立草稿與新料號，但在進入受控邊界後留下必要稽核證據。

## 2. 核心原則

### 2.1 圖號與版次

- 圖號是受控圖面的主體。
- 版次是圖號的重要狀態，不使用 `V` 前綴。
- 原圖號進版入口代表使用者已選擇「同一圖號進新版次」。
- 因此在原圖號進版流程中，即使 FFF 確認影響，也不建立新圖號；只建立新料號，並要求新版圖面中的料號一致。

### 2.2 料號

- 料號無版次。
- 料件若確認違反 Form / Fit / Function，應取得新流水號形成新料號。
- 舊料號可被新料號取代，但舊 BOM 仍可繼續使用舊料號。
- 料號模組與圖號進版頁都可以建立新料號，但必須共用同一套「新料號草稿」流程。

### 2.3 BOM

- BOM 自身有版次。
- BOM 不直接記錄圖號版次；預設解析為最新版 released 圖面。
- 已發行 BOM 不因新圖面或新料號自動變更。
- 未發行 BOM 草稿若引用被取代料號，需重新確認後才能送審。

### 2.4 ISO 9001 管制邊界

系統不應把所有草稿動作都當成正式受控文件處理。ISO 9001 需要的是受控流程、設計變更與正式輸出的可追溯證據，不是對每個未提交草稿欄位做過度紀錄。

因此本規格區分：

- `預留草稿號`：尚未進入 PDM 受控關聯，可快速編輯、作廢與回收。
- `受控料號`：已進入送審、圖面、BOM 或替代關聯等受控網路，不可回收號碼。

## 3. 名詞定義

| 名詞 | 定義 |
|---|---|
| FFF | Form、Fit、Function。用來判定變更是否改變料件本質。 |
| FFF 無影響 | RD 判定圖面變更不影響 Form / Fit / Function。 |
| FFF 疑似影響 | RD 無法直接排除 FFF 影響，需審核者確認。 |
| FFF 確認影響 | RD 確認變更影響 Form / Fit / Function，需新料號。 |
| 預留草稿號 | 尚未送審、未綁定受控圖面、未被 BOM 或替代關聯引用的料號草稿。 |
| 受控料號 | 已送審、已綁定圖面、已被 BOM 引用或已建立替代關聯的料號。 |
| 替代料號 | 取代來源料號的新料號。 |
| 圖號進版產生料號 | 在原圖號進版流程中，因 FFF 確認影響而建立的新料號。 |

## 4. 角色責任

| 角色 | 責任 |
|---|---|
| RD | 填寫 FFF 判定、建立新料號草稿、上傳新版圖面、確認圖面料號。 |
| 發行審核者 | 確認 RD 的 FFF/BOM 判定；對疑似影響做結論；核准或退回。 |
| 料號管理員 | 管理草稿號回收、部門草稿視圖與例外處理。 |
| BOM Owner | 接收 BOM 草稿需重新確認提示，決定是否更新 BOM。 |

## 5. 圖號進版流程

### 5.1 進版入口

原圖號進版頁代表使用者已選擇「沿用原圖號」。系統不可在此流程中改成建立新圖號。

進版頁應提供：

- 新版次欄位。
- 變更原因分類。
- Form / Fit / Function 三態判定。
- BOM 判定與審核確認動作。
- 若 FFF 確認影響，同頁建立新料號草稿與圖面料號比對。

### 5.2 變更原因分類

固定選項：

- 標註 / 文字修正
- 尺寸 / 公差修正
- 材質 / 製程修正
- BOM / 料件影響
- 其他

### 5.3 FFF 三態

每一項 `Form / Fit / Function` 都必須能選：

- 無影響
- 疑似影響
- 確認影響

### 5.4 FFF 全部無影響

流程結果：

- 允許沿用原料號。
- 預設 `BOM 不進版，待審核者確認`。
- 審核者核准前必須按下 `確認 BOM 不進版`。

### 5.5 任一 FFF 疑似影響

流程結果：

- 允許沿用原料號送審。
- 案件標記為高風險。
- 審核者必須做出二選一結論：
  - `退回補新料號`
  - `確認沿用原料號`
- 疑似影響不可停留為最終狀態。

### 5.6 任一 FFF 確認影響

流程結果：

- 不允許沿用原料號送審。
- 必須在同頁建立新料號草稿。
- 圖號沿用原圖號並進新版次。
- RD 必須上傳新版圖面。
- 系統讀取圖面料號為主，RD 可手動修正讀取值後比對。
- 圖面料號必須等於新料號，否則不得送審。

審核者核准後一次完成：

- 發行新版圖面。
- 發行新料號。
- 建立新舊料號替代關聯。
- 舊料號標記為被新料號取代。
- 舊 BOM 可繼續使用。

## 6. 新料號草稿流程

### 6.1 入口

料號模組提供三種新料號入口：

- 建立全新料號
- 建立替代料號
- 從圖號進版建立新料號

三種入口都進入同一套新料號草稿流程。

### 6.2 草稿清單

系統只有一個「料號草稿清單」，用類型標籤區分：

- 全新料號
- 替代料號
- 圖號進版產生

清單至少顯示：

- 新料號
- 料件類型
- 草稿類型
- 來源料號
- 來源圖號 / 來源版次
- 狀態
- 建立者
- 部門

草稿清單預設顯示：

- 建立者自己的草稿
- 使用者有權限的部門草稿

### 6.3 料件類型

建立新料號時必填：

- 自製件
- 外購件
- 標準件

料件類型任何狀態都可改，但必須留下修改紀錄。  
一旦料件類型改變，系統必須重新計算送審門檻。

### 6.4 自製件送審門檻

自製件替代料號送審前必須滿足：

- 有新版圖面。
- 圖面料號與新料號一致。

未滿足時仍可維持 `草稿`，但不得送審。

### 6.5 外購件 / 標準件送審門檻

外購件與標準件不強制 RD 填原因或附件。  
審核者只有 `核准 / 退回`，由審核者把關。

注意：若同一來源料號同時存在多個替代草稿，系統需顯示警告，並要求以用途類型或替代脈絡避免混淆。

### 6.6 同來源多草稿

同一來源料號允許建立多個替代草稿，但系統必須：

- 顯示已有未完成替代草稿警告。
- 要求標示用途類型，例如 FFF 變更、材料替代、客戶版本、供應商替代。
- 當其中一筆正式發行後，其他同來源未完成草稿自動標記為 `需重新確認`，不得直接送審。

## 7. 料號草稿狀態機

狀態只採五種：

- 草稿
- 待審核
- 已發行
- 需重新確認
- 作廢

### 7.1 狀態說明

| 狀態 | 說明 |
|---|---|
| 草稿 | 可快速編輯，尚未進入正式審核。 |
| 待審核 | 已送審，進入受控審核流程。 |
| 已發行 | 審核通過，正式可用。 |
| 需重新確認 | 草稿前提已改變，不得直接送審。 |
| 作廢 | 草稿或預留號已取消。 |

### 7.2 需重新確認觸發條件

自動發生於：

- 同來源料號已有另一筆替代草稿正式發行。
- 來源圖號已有更新的 released 版次。

## 8. 預留草稿號與回收規則

### 8.1 受控邊界

料號從 `預留草稿號` 轉成 `受控料號` 的條件：

- 被 BOM 引用。
- 被替代關聯引用。
- 上傳圖面到 PDM。
- 送審。

受控料號不可回收。

### 8.2 回收規則

預留草稿號作廢後：

- 預設進入 7 天回收冷卻期。
- 建立者本人與料號管理員可選擇立即回收。
- 回收後重新發出的號碼，一般使用者畫面不顯示曾回收標記。
- 稽核事件仍需可查「曾預留、作廢、回收、重新發出」。

### 8.3 草稿有效期限

- 預留草稿號有效期限為 30 天。
- 逾期後只提醒，不自動作廢。
- 提醒對象：建立者 + 料號管理員。

### 8.4 草稿事件紀錄

預留草稿號只記錄關鍵事件：

- 建立
- 料件類型變更
- 來源料號變更
- 作廢
- 回收

受控後另依審核、圖面、BOM 與替代關聯規則留痕。

## 9. 審核規則

### 9.1 FFF 全部無影響

審核者核准前必須按下：

- `確認 BOM 不進版`

紀錄內容：

- 結果
- 審核者
- 時間
- 確認動作

### 9.2 FFF 疑似影響

審核者必須選擇：

- `退回補新料號`
- `確認沿用原料號`

退回原因不強制，但系統需保留退回事件。

### 9.3 FFF 確認影響

審核者核准後一次完成：

- 發行新版圖面。
- 發行新料號。
- 建立替代關聯。
- 舊料號標記為被取代。

## 10. BOM 影響規則

### 10.1 未發行 BOM 草稿

當新料號發行、舊料號被取代後，含舊料號的未發行 BOM 草稿：

- 自動標記 `需重新確認`。
- 不得直接送審。

### 10.2 已發行 BOM

已發行 BOM：

- 不自動變更。
- 只提示有新料號可評估。
- 舊 BOM 可繼續使用舊料號。

### 10.3 BOM 編輯使用被取代料號

允許使用，但系統必須：

- 顯示「已被新料號取代」警示。
- 要求使用者確認後才能保存或送審。

## 11. 稽核與歷程

### 11.1 圖號進版 FFF 判定歷程

記錄每次送審與退回後重填的判定。  
不記錄每次欄位改動。

### 11.2 新料號草稿歷程

記錄：

- 建立
- 料件類型變更
- 來源料號變更
- 作廢
- 回收
- 送審
- 發行

### 11.3 審核者確認紀錄

記錄：

- 結果
- 審核者
- 時間
- 必要確認動作

必要確認動作包含：

- 確認 BOM 不進版
- 確認沿用原料號
- 退回補新料號
- 核准新料號與新版圖面發行

## 12. 建議資料模型

實作時可依現有 schema 調整，但至少需要能表達下列資料：

| 資料 | 用途 |
|---|---|
| `part_number_drafts` 或既有 `part_numbers` 草稿欄位 | 管理預留草稿號、狀態、料件類型、草稿類型。 |
| `part_number_events` | 管理草稿與受控料號關鍵事件。 |
| `part_replacement_links` | 管理新舊料號替代關聯。 |
| `drawing_revision_fff_assessments` | 管理圖號進版 FFF 判定與重送審歷程。 |
| `review_confirmation_events` | 管理審核者必要確認動作。 |
| `bom_reconfirmation_flags` | 管理 BOM 草稿需重新確認狀態。 |

## 13. RD 開發切片建議

### Phase 1：資料模型與共用服務

- 建立草稿料號、受控邊界、替代關聯與事件紀錄資料能力。
- 建立料號回收冷卻期與立即回收權限規則。
- 建立 `需重新確認` 計算服務。

### Phase 2：料號模組

- 單一料號草稿清單。
- 三種建立入口。
- 料件類型與草稿類型標籤。
- 同來源多草稿警示。
- 預留號作廢、回收與逾期提醒。

### Phase 3：圖號進版頁

- 變更原因分類。
- Form / Fit / Function 三態判定。
- FFF 確認影響時同頁產生新料號草稿。
- 新版圖面料號讀取、RD 修正讀取值與一致性比對。

### Phase 4：審核頁

- `確認 BOM 不進版`。
- `退回補新料號` / `確認沿用原料號`。
- FFF 確認影響時一次核准新版圖面、新料號與替代關聯。

### Phase 5：BOM 影響提示

- 未發行 BOM 草稿自動標記需重新確認。
- 已發行 BOM 僅提示。
- BOM 編輯使用被取代料號時警示與確認。

## 14. 驗收標準

### 14.1 圖號進版

- FFF 全部無影響時，可沿用原料號，審核者必須確認 BOM 不進版。
- 任一 FFF 疑似影響時，可送審但標記高風險，審核者必須做出明確結論。
- 任一 FFF 確認影響時，未建立新料號與未完成圖面料號一致比對前不得送審。

### 14.2 料號草稿

- 料號模組與圖號進版頁能接續同一筆草稿。
- 自製件草稿未補新版圖面或圖面料號不一致時不得送審。
- 外購件與標準件不強制 RD 填原因或附件。
- 預留草稿號作廢後進入 7 天冷卻期，且建立者或料號管理員可立即回收。

### 14.3 BOM

- 新料號發行後，未發行 BOM 草稿引用舊料號時自動標記需重新確認。
- 已發行 BOM 不自動變更。
- BOM 編輯使用被取代料號時需顯示警示並要求確認。

### 14.4 稽核

- 圖號進版記錄每次送審與退回後重填的 FFF 判定。
- 新料號草稿記錄建立、料件類型變更、來源料號變更、作廢、回收、送審、發行。
- 審核者確認紀錄包含結果、審核者、時間與必要確認動作。

## 15. 範圍外

第一版不包含：

- 自動修改 CAD 檔案內料號。
- 自動修改 BOM 已發行版本。
- 自動建立 BOM 新版草稿。
- 強制外購件 / 標準件上傳規格書或附件。
- 每個草稿欄位的完整版本歷程。
- 在原圖號進版流程中建立新圖號。

## 16. 風險與護欄

| 風險 | 護欄 |
|---|---|
| 草稿太重，工程師不願使用 | 預留草稿號保持低摩擦，只記關鍵事件。 |
| 回收號造成稽核疑慮 | 只有預留草稿號可回收；受控後不可回收；內部稽核事件可查。 |
| 同來源多個替代草稿混亂 | 允許但顯示警告，且正式發行一筆後其他草稿需重新確認。 |
| FFF 疑似影響留下模糊結論 | 審核者必須選擇退回補新料號或確認沿用原料號。 |
| BOM 被自動改壞 | 已發行 BOM 不自動變更，只提示；未發行草稿需重新確認。 |

## 17. 未決問題

- 用途類型的第一版固定選項是否採 `FFF 變更 / 材料替代 / 客戶版本 / 供應商替代 / 其他`。
- 料號管理員的角色權限是否沿用既有 PDM Admin，或新增 Part Number Manager。
- 圖面料號讀取以 SolidWorks 屬性、檔名、PDF/OCR 哪個來源為第一優先。
- `需重新確認` 的 UI 呈現要放在草稿清單、BOM 編輯頁、或待辦中心。

## 18. QA 驗證方向

QA 驗證計畫需至少涵蓋：

- FFF 無影響、疑似影響、確認影響三條圖號進版流程。
- 自製件、外購件、標準件三種料件類型的送審門檻。
- 料號草稿跨入口接續。
- 預留草稿號作廢、冷卻期、立即回收、重新發出。
- 受控料號不可回收。
- 新料號發行後 BOM 草稿需重新確認。
- 已發行 BOM 不被自動修改。
- 審核者必要確認動作是否留痕。
